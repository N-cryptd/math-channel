# Math Channel Strategy

## Channel Identity
- **Name**: TBD (suggestions below)
- **Format**: Manim-animated mathematics explainer videos
- **Style**: 3Blue1Brown-inspired but with its own visual identity
- **Language**: English (largest audience for math education)
- **Goal**: Complete mathematics curriculum from arithmetic to graduate-level topics

## Name Suggestions
1. **The Manifold** — geometric, mathematical, implies depth
2. **Axiom** — clean, authoritative, memorable
3. **Proof by Animation** — describes the format
4. **Visual Calculus** — if starting calculus-first
5. **Math in Motion** — straightforward
6. **Null Space** — clever double meaning (math term + creative void)
7. **The Derivation** — implies the step-by-step approach

## Visual Identity
- **Color Palette**: Warm Academic (approachable for learners)
  - Background: #2D2B55 (deep indigo)
  - Primary: #58C4DD (cyan-blue) — key concepts
  - Secondary: #83C167 (green) — supporting elements
  - Accent: #FFFF00 (yellow) — highlights, "aha" moments
- **Typography**: Monospace throughout (Menlo) for consistency
- **Outro**: Subscribe CTA + next video preview (3s)
- **Intro**: Channel logo animation (3-5s, reusable template)

## Video Format
- **Length**: 8-15 minutes per video (long enough for depth, short enough for attention)
- **Frequency**: 2-3 videos per week initially
- **Structure per video**:
  1. Title card (3s)
  2. Hook — pose a question or show a surprising result (30-60s)
  3. Build-up — develop the concept with animations (5-10 min)
  4. "Aha moment" — the key insight (30-60s)
  5. Summary + preview of next video (30s)
  6. Outro (3s)

## Narrative Philosophy
- **Geometry before algebra** — show the shape, then the equation
- **Motivation before definition** — why do we need this?
- **Examples before theorems** — see it work, then prove it
- **One idea per video** — deep understanding over breadth
- **Continuous story arcs** — each video references the last, builds to the next

## Audio Plan
- **Narration**: TTS (ElevenLabs or similar) for consistent quality and speed
- **Background music**: Subtle ambient (no lyrics, low volume)
- **Sound effects**: Minimal — optional soft tones for reveals

## Upload Strategy
### Phase 1: Launch (Videos 1-20)
- Upload 3-5 videos before announcing the channel
- Start with the Calculus playlist (highest demand, gateway to everything)
- Cross-reference 3Blue1Brown's Essence of Calculus but with different pace/depth

### Phase 2: Growth (Videos 21-60)
- Expand to Linear Algebra playlist (second highest demand)
- Add Pre-calculus foundations for students who need them
- Start engaging in comments, community posts

### Phase 3: Scale (Videos 61+)
- Branch into multiple playlists simultaneously
- Introduce Real Analysis, Abstract Algebra, Complex Analysis
- Create "bridge" videos connecting playlists

## Curriculum Design Principles
1. **Self-contained playlists** — each playlist is a complete mini-course
2. **Cross-references** — link between playlists where topics connect
3. **Prerequisites stated** — each video/playlist says what you need to know
4. **Difficulty progression** — within each playlist, difficulty increases gradually
5. **Review videos** — periodic "what we've learned so far" compilations
6. **Exercise videos** — optional problem-solving videos with walkthroughs

## Monetization (long-term)
- YouTube Partner Program (after 1K subs + 4K watch hours)
- Patreon for early access + bonus content
- No ads on educational content if possible (user experience first)
