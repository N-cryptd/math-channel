## Video Outline (~10 min)

### Scene 1: Hook — The Lifting Problem (5s intro + content)
- Motivating question: Can every path in a space be "lifted" to another space?
- The real line wraps around the circle — the exponential map
- Content budget: title + 3 key ideas

### Scene 2: Definition of Covering Space (section 1)
- Definition: p: X̃ → X is a covering map if every x in X has a neighborhood U
  whose preimage is a disjoint union of open sets, each homeomorphic to U
- Key terms: base space X, covering space X̃, covering map p, fiber p⁻¹(x)
- Visual: R → S¹ (the canonical example)
- Content budget: definition formula + 3 labels

### Scene 3: The Exponential Map (section 2)
- p(t) = e^(2πit) maps R onto S¹
- Each interval [n, n+1] maps onto the circle
- The fiber p⁻¹(1) = Z (all integers)
- Visual: line wrapping around circle
- Content budget: formula + 2 text items + visual

### Scene 4: More Examples (section 3)
- Double cover: S¹ → S¹ by z ↦ z²
- Cylinder covering torus
- Universal cover of the figure-eight: infinite tree
- Content budget: progressive reveal of 4 examples

### Scene 5: Path Lifting (section 4)
- The path lifting property: given γ in X and x̃ in p⁻¹(γ(0)),
  there exists a unique lift γ̃ in X̃ with γ̃(0) = x̃
- Homotopy lifting property (stronger)
- Content budget: statement + formula + illustration

### Scene 6: Connection to Fundamental Group (section 5)
- Covering spaces compute fundamental groups
- Theorem: π₁(S¹) ≅ Z via the covering R → S¹
- Monodromy action of π₁(X) on the fiber
- Content budget: theorem + 3 consequences

## Key Formulas
- p: X̃ → X (covering map)

- Path lifting: γ̃(0) = x̃, p ∘ γ̃ = γ
