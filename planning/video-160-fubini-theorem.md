## Scene Plan

### Scene 1: Hook — The Double Integral Question (30s)
**Content budget:** Title + 1 formula + 2 text items
- "In calculus, we computed double integrals by iterating. But when does this actually work in the Lebesgue setting?"
- Motivation: ∫∫ f d(μ×ν) vs ∫[∫ f dν] dμ
- Three items about when iterated integrals are valid

### Scene 2: Product Sigma-Algebras (40s)
**Content budget:** Section divider + title + definition + 1 formula
- Σ_X ⊗ Σ_Y = σ({A × B : A ∈ Σ_X, B ∈ Σ_Y})
- Generated by rectangles (measurable rectangles)
- Key property: the product sigma-algebra is the smallest containing all rectangles

### Scene 3: Product Measures (45s)
**Content budget:** Title + formula + 2 items
- (μ × ν)(A × B) = μ(A) · ν(B)
- Carathéodory extension builds the measure from rectangles
- Sigma-finite assumption ensures uniqueness

### Scene 4: Fubini's Theorem (50s)
**Content budget:** Section divider + title + theorem statement in formula box + 1 text
- Conditions: f ∈ L¹(μ × ν), σ-finite spaces
- ∫_X×Y f d(μ×ν) = ∫_X [∫_Y f(x,y) dν(y)] dμ(x)
- The order of integration can be swapped
- "Almost everywhere" caveats

### Scene 5: Tonelli's Theorem (40s)
**Content budget:** Title + theorem in formula box + 1 text
- For f ≥ 0 measurable (not necessarily integrable)
- Finiteness of one iterated integral implies integrability
- Complementary: Tonelli proves integrability, Fubini computes the value

### Scene 6: Fubini-Tonelli Strategy (35s)
**Content budget:** Title + 3-step strategy items
- Step 1: Check non-negativity → apply Tonelli to establish integrability
- Step 2: If integrable → apply Fubini to swap order freely
- Step 3: If sign-changing → Tonelli on |f| first

### Scene 7: Worked Example (50s)
**Content budget:** Title + setup + formula + result
- Example: ∫∫ e^{-(x²+y²)} dx dy over R²
- Inner integral: ∫ e^{-x²} dx = √π (Gaussian)
- Product: π
- Compare with polar coordinates approach

### Scene 8: Counterexample — When Fubini Fails (45s)
**Content budget:** Title + counterexample setup + formula + explanation
- f(x,y) = (x²-y²)/(x²+y²)² on [0,1]×[0,1]
- Iterated integrals give different values (+π/4 vs -π/4)
- Why? f is NOT integrable (|f| has infinite product integral)
- This demonstrates the L¹ hypothesis is essential

### Scene 9: Summary + Outro (35s)
**Content budget:** Takeaways (3-4 items) + outro
- Product sigma-algebra generated by rectangles
- Tonelli: non-negative → existence
- Fubini: integrable → equality + swap
- Strategy: Tonelli on |f|, then Fubini
- Tease next: Lebesgue vs Riemann (Video 161)
