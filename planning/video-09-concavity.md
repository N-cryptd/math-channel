# Video 09: Concavity & Second Derivative Test
## Overview
- **Topic**: Concavity, inflection points, second derivative test for extrema
- **Hook**: "You found a critical point. But is it a peak or a valley? The second derivative gives the answer instantly."
- **Aha moment**: The second derivative measures *curvature*, not slope — it tells you the shape of the graph
- **Target audience**: Watched Videos 01-08
- **Length**: ~12 min

## Scenes
1. **Hook** — Recap critical points and the sign chart. Problem: what if there are many critical points? Second derivative gives a faster test. (~60s)
2. **Concavity Visual** — Show a curve with concave up (holds water, f'' > 0, smiley face) and concave down (spills water, f'' < 0, frowny face). Use color coding. (~90s)
3. **Inflection Points** — Point where concavity changes. Show on a graph. f''(c) = 0 is necessary but not sufficient. Example: f(x) = x^4 at x=0. (~60s)
4. **Second Derivative Test** — At critical point where f'(c) = 0: if f''(c) > 0 → local min, if f''(c) < 0 → local max, if f''(c) = 0 → inconclusive (use first derivative test). Animated decision tree. (~90s)
5. **Example** — Find and classify extrema of f(x) = x^3 - 3x + 2. Compute f'(x) = 3x^2 - 3, critical points x = ±1, f''(x) = 6x, classify. (~60s)
6. **Comparison** — Side-by-side comparison of 1st vs 2nd derivative test. When to use which. 2nd is faster but doesn't always work. (~45s)
7. **Recap** — "Next: Curve Sketching — putting it all together." (~45s)
