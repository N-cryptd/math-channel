## Scene Plan

### Scene 1: Hook — "Measuring Sets" (~50s)
- "In probability, we want to assign a number — a probability — to events."
- "In integration theory, we want to assign a number — a measure — to sets."
- "But there's a catch: not every collection of sets allows a consistent measure."
- Visual: a circle (the "universe") with two overlapping regions A and B colored differently
- "We need a family of sets that is rich enough to capture the events we care about, but well-behaved enough to avoid paradoxes."
- "This family is called a sigma-algebra."

### Scene 2: From Algebras to Sigma-Algebras (~70s)
- Start with the intuition: "Suppose X is a set. What properties should a useful family of subsets have?"
- Property 1: "It should contain the whole set X and the empty set."
- Visual: full circle labeled X, then empty set symbol
- Property 2: "It should be closed under complements. If A is measurable, so is its complement."
- Visual: A shaded region, then complement region shaded
- Property 3: "It should be closed under finite unions."
- "These three properties define an ALGEBRA of sets."
- Definition box: Algebra of sets — (1) X in F, (2) A in F implies A^c in F, (3) A,B in F implies A∪B in F
- "An algebra is good, but for measure theory we need something stronger: closure under COUNTABLE unions, not just finite ones."
- Visual: dots representing a countable sequence of sets, ellipsis, then union symbol
- Definition box: Sigma-algebra — same as algebra but with countable unions
- "The sigma signals that we now allow countably infinite operations."

### Scene 3: Formal Definition and Axioms (~60s)
- Full formal definition of sigma-algebra on a set X
- Visual: definition card with the three axioms color-coded (PRIMARY, SECONDARY, ACCENT)
- "A sigma-algebra F on X is a collection of subsets of X satisfying:"
  1. X ∈ F (and hence ∅ ∈ F)
  2. If A ∈ F, then A^c ∈ F (complement closure)
  3. If A₁, A₂, A₃, ... ∈ F, then ∪ᵢ Aᵢ ∈ F (countable union closure)
- Key equivalences derived from the axioms:
  - Countable intersections: De Morgan's law
  - ∅ ∈ F from axiom 1 + axiom 2
  - Difference: A \ B = A ∩ B^c
- Visual: each derived property shown with brief color animation

### Scene 4: Examples (~70s)
- Example 1: The trivial sigma-algebra F = {∅, X}
  - Visual: only two items, full set and empty
  - "The smallest possible sigma-algebra. Not very useful."
- Example 2: The power set P(X)
  - Visual: for a set with 3 elements, show all 8 subsets
  - "The largest sigma-algebra. Every subset is measurable."
  - "Always a sigma-algebra — the power set is closed under any set operation."
- Example 3: The countable/co-countable sigma-algebra on R
  - Visual: R with some points highlighted (countable = measurable), complement shaded
  - "Contains all countable sets and all sets whose complement is countable."
  - "This is NOT the standard Borel sigma-algebra — it's a different one."
  - Verify the three axioms briefly

### Scene 5: The Borel Sigma-Algebra (~70s)
- "The most important sigma-algebra in all of mathematics: the Borel sigma-algebra B(R)."
- Motivation: "The power set P(R) is too large — it contains non-measurable sets (Vitali sets)."
- "We need a sigma-algebra that contains all open intervals but isn't too big."
- Definition: "The Borel sigma-algebra B(R) is the SMALLEST sigma-algebra containing all open sets of R."
- Visual: start with an open interval, progressively add unions, intersections, complements — a growing web of sets
- "Equivalently: generated by all open intervals (a,b), or all closed intervals [a,b], or all half-open intervals [a,b)."
- Visual: list of equivalent generators
- "Every open set in R is a countable union of open intervals, so generating by open intervals suffices."
- "B(R) contains: all open sets, all closed sets, all countable unions of closed sets (F-sigma), all countable intersections of open sets (G-delta)"
- Visual: nested diagram showing hierarchy of Borel sets

### Scene 6: Generated Sigma-Algebras (~60s)
- "Given any collection C of subsets of X, there exists a SMALLEST sigma-algebra containing C."
- Formal statement: sigma(C) = intersection of ALL sigma-algebras containing C
- Visual: multiple sigma-algebras overlapping, their intersection highlighted
- "This is well-defined because the intersection of any family of sigma-algebras is a sigma-algebra."
- Quick proof sketch (visual):
  - X is in every sigma-algebra → X is in the intersection
  - If A is in the intersection, A is in every sigma-algebra, so A^c is in every → A^c in intersection
  - Countable unions: similar
- "The Borel sigma-algebra is exactly sigma({open intervals})."

### Scene 7: Measurable Spaces (~45s)
- "A measurable space is a pair (X, F) where X is a set and F is a sigma-algebra on X."
- Visual: X as a large circle, F as a labeled family
- "The elements of F are called MEASURABLE sets."
- "We haven't defined any measure yet — we're just specifying WHICH sets are allowed to be measured."
- Analogy: "A sigma-algebra is like a menu. A measurable space is the restaurant. The measure (coming next) tells you the prices."
- "Why this abstraction? Because different measures can live on the same measurable space."
- Visual: same (R, B(R)) with three different measures listed: Lebesgue, probability P, counting measure

### Scene 8: Summary (~40s)
- Recap the key definitions:
  - Algebra of sets: finite unions + complements
  - Sigma-algebra: countable unions + complements
  - Borel sigma-algebra: smallest sigma-algebra containing open sets
  - Generated sigma-algebra: smallest sigma-algebra containing a given collection
  - Measurable space: (X, F) — the domain for a measure
